คำนวณพื้นที่ผิวสะพานคนเดินข้าม

กำหนดจำนวนช่วง เสา และบันได แล้วแก้ไขมิติของแต่ละชิ้นส่วนตามแบบสำรวจ

ข้อมูลแบบสำรวจ / Bridge survey

ถ้ามีรายงานที่จับคู่กับรหัสสะพาน ระบบจะเติมข้อมูลตั้งต้นจากรายงานให้แก้ไขต่อได้

ความสูงช่องลอดจราจรแยกจาก H ของบันไดเสมอ ระบบจะไม่คัดลอกค่าให้อัตโนมัติ กรอกความสูงรวม H แยกในมิติบันไดแต่ละฝั่งเมื่อวัดได้ และใช้ hard fill สำหรับปริมาณที่ยังคำนวณไม่ได้

ข้อมูล L/A/B/C/S และช่องลอดเป็นค่าที่อ่านได้จากรายงานที่จับคู่กัน รูปแบบบันไดและจำนวนเสาเป็นตัวตั้งต้นให้เลือกเอง ไม่ใช่มิติสำรวจจากรายงาน พื้นที่ PU Deck จาก A × L เป็นพื้นที่รวมก่อนหักสิ่งกีดขวาง ใช้ความกว้างสุทธิหรือ Hard fill เมื่อต้องการปริมาณงานจริง

สมมติฐานการคำนวณ / Calculation basis

บันไดใช้ preset ตาม Type และเปลี่ยนเฉพาะ B (ความกว้าง) กับ H (ความสูงรวม): ลูกตั้งสูงสุด 0.175 m และลูกนอน 0.30 m เป็นค่าประมาณที่เลือกใช้ ไม่ใช่มาตรฐานที่วัดหรือสอบเทียบจากแบบจริง. จำนวนลูกตั้ง N = max(2, ceil(H/0.175)) สำหรับ Type 1 และ N = max(3, ceil(H/0.175)) สำหรับ Type 2/3; Type 2/3 กันเที่ยวบน 4 ลูกตั้ง (หรือน้อยกว่านั้นเมื่อ N ต่ำ) แล้วแบ่งส่วนล่างเป็น 2 เที่ยว. ชานพักเป็นสี่เหลี่ยมที่อนุมานจาก B และสมมติอยู่นอกความยาว Span L เพื่อไม่ให้คิดพื้นที่ซ้อน: Type 1 = 1 ชานกลางทาง (B²), Type 2 = ชานกลางทาง + ชานกลับตัว (3B²), Type 3 = ชานกลางทางสองแห่ง + ชานร่วมหนึ่งแห่ง (4B²); ไม่เพิ่มชานเชื่อมก่อนเข้า Deck แยกอีกก้อน. Type 3 นับสองแขนทางขึ้นและเที่ยวบนร่วมเพียงครั้งเดียว; route ก็รวมทางร่วมเพียงครั้งเดียว. พื้นที่ PU Stair = B × ผลรวม run ของลูกนอนจริง + พื้นที่ชาน; Mortar ใต้บันได = B × ผลรวมความยาวลาดของเที่ยวจริง + พื้นที่ชาน. หน้าตัด Double-T คิดพื้นบนเป็น B × L และพื้นที่ซี่ลง/ท้องพื้นเป็นผิวซ่อมด้วย mortar. หัวเสาแบบบานคิดพื้นที่ผิวลาดของหัวเสาร่วมกับผิวรอบลำเสา. พื้นที่ทาสีหรือพื้นที่อื่นที่ไม่อยู่ใน 4 หมวดนี้ไม่ได้ถูกรวมอัตโนมัติ
